참조 자료형
   대부분의 기본 자료형의 변수는 프로그램 메모리중 stack에 공간을 지정해서 사용함.
하지만, 참조 자료형은 stack 공간에 data를 저장하지 않고, heap이란 메모리에 데이터를 저장.
(heap이란 데이터에 만들어 놓은 주소를 data에 저장, heap은 실행중에 만들어진 데이터를 저장하는 곳.)
   stack에 저장되는 변수에는 heap에 있는 데이터 주소(**)를 저장하고, 변수를 부를 때..
주소를 참조해서 data 불러오게 된다.   

 ex) 종류 - String, 배열, object 타입(클래스...) etc..

형변환 (casting)
  컴퓨터는 계산을 할 때, 같은 데이터 타입을 가지고 계산한다.
  따라서 숫자인 경우에 다른 데이터 타입이면, 큰 데이터 타입으로 변경해서 계산을 한다.
ex) 
10(int) + 20(int) = 30(int) 
10(byte) + 20(int) => 10(byte -> int) + 20(int)
10(short) + 20(byte) => 10(short) + 20(byte -> short)
10(int) + 20.0f(float) => 30.0f


기본 자료형의 크기 순
byte < short < int <long < float < double

위 형변환 중에 자동으로 형변환이 일어나는 경우를 "자동(묵시적)" 형변환...
모든 형변환이 자동으로 일어나는 것은 아님. 때문에 강제로 형변환을 해야 할 경우도 있음
강제로 형변환을 할 경우, 
ex) 
10(int) + (int)30.3f => 결과는 int였으면 좋겠음  
10 + (int)30.3f => 40(int)
