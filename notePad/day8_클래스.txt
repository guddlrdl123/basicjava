1) 객체지향 프로그램이란?
객체지향 프로그래밍이란, 다양한 객체(Object)들의 관계가 존재하고, 이들 간에 서로 상호작용을
하고 있습니다. 그런데, 이런 객체들의 관계를 정립하지 않고 따로 관리하게 되면, 
데이터 관리시 어렵게 됩니다.
때문에 객체지향 파라다임으로 전환해서 관련된 내용을 하나의 객체로 묶어서 관리하는 형식으로
프로그래밍을 하는 것을 말합니다.

[객체지향 프로그래밍의 특징]
 1. 상속
 2. 다형성
 3. 추상화
 4. 캡슐화

2) 클래스? 객체?
 클래스란, 객체의 생성시 필요한 모든 정보를 포함한 설계(구성)도를 말함.
 객체란, 클래스를 사용하여 실제로 구현되어 만들어진 것들을 의미함.

	       [ 클래스 ]                                          [ 객체 ]
  (자동차 설계도) ---> 자동차 부품들과 기능 --->      자동차 생산
		- 엔진			    기아 - 산타페	
		- 핸들			    기아 - 니로
		- 바퀴			    기아 - 모닝
		- 문짝들			    현대 - 아반테
		- 브레이크		    현대 - 소나타
		... 			           ...
		- 전진()
		- 후진()
		- 좌회전()
		...

3) 클래스 구성

- 클래스 생성
class 키워드 사용.

syntax
    public class 클래스명 {
    	... 클래스에 대한 정의
	// field(attribute, 멤버) - 변수
	// constructors(생성자) - 메서드
	// methods (메서드)
    }

1. 필드(속성, 멤버) - 클래스에서 사용할 변수. 명사적 특징을 가짐.
    [제한자] [타입] [변수명];
ex) public static final int MAX;   // 상수형 변수
     public static int index;	  // 정수 변수

2. 생성자 - 클래스를 통해서 객체를 생성하기 위해서 사용됨.
    [제한자] [클래스명] (파라미터 리스트) {}
    public CustomerManager( ... ){ ... }

3. 메서드 - 객체가 가지고 있는 명사적 특징 (변수)을 표현(기능)합니다.

   [제한자] [반환타입] [메서드 이름]([파라미터 리스트]) {
        ... 실행할 코드들이 작성됨. 
   }

   ex) main 메서드
    public static void main(String[] args) {
	...
    }

- 객체 선언 및 생성
syntax
      클래스명 변수명;
      클래스명 변수명 = new 클래스명(생성자)();
