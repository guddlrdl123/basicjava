## 배열 ##

int[10][ ]; (O)    -> 2차원 배열 앞자리 생략 불가, 뒷자리 생략 가능
int[ ][4];  (X)  
int[3][ ][ ];   -> 3차원도 앞자리 생략 불가

자바의 함수(메서드)
  메서드는 클래스 안에서 특정 행위를 하는 코드를 정의하는 영역.
  
  Syntax
     [제한자]  [반환타입]  [메서드]  ( [파라미터 리스트] )  {
     	... 실행할 코드들이 작성됨.
     } 

   ex) main 메서드
     public static void main(String[ ] args) {

     }

  제한자 :	 접근제한자(public, protected, defalut(공백), private), 
             사용제한자(final, abstract, static, native ... )

  반환타입 : 함수(메서드)가 외부로 값을 전달하는데 사용되는 데이터 타입을 말함.
              기본 데이터 타입, 참조형 데이터인 배열, 클래스 들이 포함됨.
              (byte, short, int, long, float, double, boolean, char, 배열, 클래스, void (리턴 값이 없음))
               ** 반환값 처리하는 키워드 : return

파라미터 리스트 : 외부에서 함수(메서드)로 전달되어진 값을 받는 항목.
		반환 타입의 void를 제외한 모든 데이터 타입이 리스트 존재할 수 있음.
