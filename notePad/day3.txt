5. 논리 연산자
(AND, OR은 앞에 무엇을 두느냐가 중요함. 숏컷 연산이 일어나기 때문)

AND[&& (&)] : 두 개의 피연산자르 비교하여 둘다 참이면 참, 하나라도 참이 아니면 거짓
  ex)  (A) &&(&) (B) 에 조건을 보고 결정.
          A - true, B - true => true
          A - true, B - false => false
          A - false, B - true => false(숏컷 연산)
          A - false, B - false => false(숏컷 연산)
 숏컷 연산이란? 이미 값이 결정되어 뒤에 있는 내용을 볼 필요가 없는 경우, 
                     컴퓨터는 뒤에 내용을 처리하지 않고 지나감.

OR[ || ( | )] : 두 개의 피연산자를 비교해서 둘 중 하나라도 참이면 참, 둘다 거짓이면 거짓
  ex)  (A) || ( | ) (B) 에 조건을 보고 결정.
          A - true, B - true => true (숏컷 연산)
          A - true, B - false => true(숏컷 연산)
          A - false, B - true => true
          A - false, B - false => false
 
XOR [^] : 둘 중에 하나라도 참이면 참. 단, 둘 다 참이거나 거짓이면 거짓. (비트)
  ex)  (A) ^ (B) 에 조건을 보고 결정.
          A - true, B - true => false
          A - true, B - false => true
          A - false, B - true => true
          A - false, B - false => false

NOT [ ! ] : 피연산자 항이 하나인 경우로 참 -> 거짓, 거짓 -> 참
  ex) ! (A)
      A - true => false
      A - false => true

4.6 비트 연산 (0 - false와 같이 생각, 1 - true라고 생각)

  AND (&) - 두 비트를 비교해서 AND 연산 처리.
                두 비트가 1인 경우 1,
                두 비트중 하나라도 0인 경우, 

  OR ( | )   - 두 비트를 비교해서 OR 연산 처리
              - 두 비트중 하나라도 1인 경우, 1
              - 두 비트가 0인 경우, 0
  
  XOR (^)  - 두 비트를 XOR 연산 처리.
              - 두 비트가 0, 1로 같지 않고, 둘 중 하나가 1인 경우, 1
              - 이외는 다 0

  NOT (~)  - 비트가 0->1, 1->0

  쉬프트 연산자 :  <<, >>, >>>
  << : 비트를 왼쪽으로 숫자 만큼 이동. (2배수의 곱과 같음. (ex)10 * 2^2)
  ex) 10 << 2
       0000 1010
   <<            2
 ------------------
       0010 1000(40)

  >> : 비트를 오른쪽으로 숫자 만큼 이동.  부호비트로 채움(2배수의 나눗셈과 같음(정수))
  ex) -11 >> 2
       11111111111111111111111111110101(-11)
   >>            2
 ------------------
       11111111111111111111111111111101(-2)

  >>> : 비트를 오른쪽으로 숫자만큼 이동. 0으로 채움
  ex) -11 << 2
       11111111111111111111111111110101(-11)
   <<                                                    2
 ------------------------------------------------------
       00111111111111111111111111111101 (1073741821)
