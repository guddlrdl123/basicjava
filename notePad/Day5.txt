ch6. 배열
 정의 : 배열은 여러 개의 데이터를 모아놓은 데이터.
 특징 : 데이터가 순서를 가지고 이어서 사용한다.
         순서를 나타내는 index라는 값으로 데이터를 불러와 사용.
         참조형 데이터입니다.
         동종의 데이터의 모음이다.

 배열의 선언 : 데이터 타입[ ] 변수명; 
	     ex) int [ ] arrInt; 
 배열의 값 생성 : 변수명 = new (데이터 타입)[size];
                   ex) arrInt = new int [5]; // int 데이터 5개인 배열 

배열 선언과 값 생성을 동시에
  1) 비어있는 배열을 생성할 때...
 ex) int[ ] arrInt = new int[5];
     int [ ]arrInt = new int[5];
     int arrInt[ ] = new int[5];
     double[ ] arrDouble = new double[5];

 2) 값이 있는 배열을 생성할 때...
  ex) int[ ] arrInt = {1, 2, 3, 4, 5};
      double[ ] arrDouble = {0.1, 0.2, 0.3};
      char[ ] arrChar = {'a', 'b', 'c', 'd'};
      boolean[ ] arrBoolean = {true, false};


        index      0	      1   	    2         3
  int[ ] arr       10       20       30        40
        addr :   4000   4004     4008     4012          
      (변수의 정수형 만큼 증가 ex. int 4byte *윈도우는 감소)
      배열의 첫 번째 주소만 저장한다.

  참조          arr[0]   arr[1]    arr[2]     arr[3]

## 향상된 for문 ##
  향상된(강화된) for문은 배열이나 배열과 같은 연속된 형태의 데이터. 나중에 배울 Collection





     for (자료형 변수: 배열|Collection 타입 데이터) {
	변수를 배열이나 Collection 타입 데이터를 순차적으로 불러 사용
}
                    
ex) 
     int[ ] arr = {10, 20, 30, 40, 50};
     for (int a: arr) {
	System.out.print(a+" ");
     } // (결과) => 10 20 30 40 50

## 다차원 배열(6.3)

 다차원 배열이란, 배열의 요소(데이터)를 배열로 가지는 형태.
   int[ ] arr = {10, 20, 30} // 요소란 10, 20, 30
 그런데, 다차원 배열은 10, 20, 30의 값이 배열인 형태의 데이터인 경우.

  3x3 행렬...

int[0][0]             int[0][2]
  10	20	30      => 10 20 30 배열    int[0]
  40	50	60      => 40 50 60 배열    int[1]
  70	80	90      => 70 80 90 배열    int[2]
int[2][0]            int[2][2]



int[ ] = {int[ ], int[ ], int[ ]}

다차원 배열의 선언.
int[ ] [ ] 변수명 = new int[size] [size];
int[ ] [ ] arr = new int[3] [3];  -> 비어있는 3x3 배열
int[ ] [ ] arr = { {10, 20, 30},
	       {40, 50, 60},
                   {70, 80, 90} }; -> 초기값 설정한 경우
  
참조시 인덱스 값  arr[0] [0], arr[0] [1], arr[0] [2]
	           arr[1] [0], arr[1] [1], arr[1] [2]
                       arr[2] [0], arr[1] [1], arr[2] [2]

2차원 배열은 배열의 요소를 1차원 배열을 가진 배열을 의미함.
3차원 배열은 배열의 요소를 2차원 배열을 가진 배열을 의미함.
4차원 배열은 배열의 요소를 3차원 배열을 가진 배열을 의미함.

int [] [] [] arr3 => 3차원 배열로 아래와 같은 2차원 배열을 가진 배열
{int [0][][], int[1][][], int [2][][]}
