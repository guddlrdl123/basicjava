[복습]

클래스의 구성
 1. 멤버변수(필드/속성)
    클래스 내에서 선언하는 변수.
    - 클래스 멤버 변수 : static 사용자 제한 사용. -> 객체 생성 없이 사용 가능
    - 인스턴스 멤버 변수 : 일반 변수 선언과 같이 사용. -> 객체 생성 해야 사용 가능
    이외는 지역변수, 매개변수

    - 상수 변수 : 변수를 상수처럼 사용. -> final이 있는 경우 상수 변수

 2. 생성자 
    클래스를 생헝하는 메서드. 특징은 메서드와 비슷하지만 목적이 객체 생성에 있다.
    생성자 오버로드...
    1) 목적이 객체 생성. 객체 생성시 동작을 위한 기본 설정. (초기화)
    2) 반환 타입은 목적이 객체이기 때문에 별도의 타입을 선언 X
    3) 식별자(이름)를 클래스명으로 사용함.

 3. 메서드
    클래스 내에서 생성되는 함수(메서드). 함수란, 기능을 의미함
    클래스 내에서 선언된 멤버변수(필스/속성) 등을 이용한 변화, 동작과 같은 움직임 등을 구현.

    
객체 생성
  변수 선어놘 같은 방식으로 객체를 선언하고 생성한다.
    [데이터 타입 - 클래스] [변수명] = [객체 생성]
  ** 기본 객체 생성 : new 클래스명(인자값..)

  ex) Pen pen1 = new pen("red"); 


=====================================================================

 - this와 this() 개념과 사용.

클래스 내에서 사용. 생성자에서 많이 사용된 this, this()

  this     	- 지금 정의된 클래스 객체를 의미 (자기 자신).
    사용되는 경우 : 변수 또는 메서드 참조시 사용.
	
  this() 	- 지금 정의된 클래스의 생성자를 의미 (자기 자신을 생성하는 생성자).
    자기 자신 클래스 내에 다른 생성자를 참조
	
cf. super, super() -> super의 의미는 부모를 의미함.

3. 제한자에 대해서 이해하고 사용할 수 있다.

 제한자는 변수, 메서드, 클래스에 대해서 제한 설정(범위)을 하는 키워드
1) 접근 제한자.
 접근 제한자는 변수, 메서드, 클래스에 대해서 Access(접근)할 수 있는 범위를 지정
			   (접근 제한 범위)

		      |모든클래스| 상속관계  | 동일패키지  | 동일클래스|
public		|     O	  |     O	     |	O       |	   O	|
protected	|     X	  |     O	     |	O       |	   O	|
 (default)		|     X	  |     X	     |	O       |	   O	|
private		|     X	  |     X	     |      X       |	   O	|

  - public은 어디서든 접근 가능해요
  - protected는 모든 클래스에서 접근은 불가. 단, 상속 또는 동일 패키지인 경우 접근이 가능함.
  - default는 접근 제한자 표시하지 않은 경우. 동일 패키지 내에 있다면 접근 가능.
  - private는 동일 클래스인 경우에만 접근이 가능합니다.

  ** 접근 제한자가 클래스에 사용되는 경우, **
     - 파일 이름으로 사용되는 클래스 - "public", "default"만 사용 가능.
     - 나머지 클래스는 public, protected,  (default), private
     


  접근 제한자가 변수 또는 메서드에 사용되는 경우,
     - 상관없이 다 사용이 가능함.

2) 사용 제한자.

ch8. 상속(p.207)
상속이란, 기존 클래스의 내용을 확장해서 새로운 클래스를 만들어 내는 것을 말합니다.

중요 특징
1) 재사용성 (코드 사용 절감 - 기존 작성된 코드(상속화된 코드)는 작성하지 않아도 됨)
2) 개발 비용의 감소 (개발 시간 단축)
3) 개발시 발생할 수 있는 문제 최소화 (안정성 향상)

문번 (syntax)
  상속은 클래스 정의시에 extend 키워드를 사용하여 상속 결정.

 ex) 
    [제한자] class [클래스명] extends [ 상속받을 클래스] {
	...
    }

  - 상속 받을 클래스는 부모가 되는 클래스를 의미함.
  - 상속의 대상 : 부모 클래스의 멤버 변수, 메서드를 상속 받음.
	       부모 클래스의 생성자는 상속 안 됨(**)

  명칭의 정의
    상속을 하는 클래스	|	상속을 받는 클래스
========================================
         부모 클래스		|                자식 클래스
         슈퍼 클래스		|                서브 클래스
         상위 클래스		|                하위 클래스
         베이스 클래스	|                파생 클래스

  
   *자식 클래스는 부모 클래스의 한 부분.*
ex) 부모 클래스는 카테고리, 자식 카테고리 안에 있는 항목
     부모 클래스 (동물 클래스), 자식 클래스(파충류, 포유류, 조류, ...)
