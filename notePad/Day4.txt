조건문 
 2. switch 구문 (switch - case 구문)
    if와 비슷한 조건 분기를 하는 코드. if중 다중 if와 가장 유사함.
    
  (예전) - 책에 있는 내용
     syntax
	switch (변수) {
	     case 값1  -> 값1을 이용한 결과 반환값;
	     case 값2  -> 값2를 이용한 결과 반환값;
	     case 값3  -> 값3를 이용한 결과 반환값;
	     default    -> 값들에 속하지 않는 경우 처리 결과 반환;
	}
   변수에 값에 대해서 숫자, 문자, 객체 타입에 따른 내용을 모두 포함해서 처리.
   값의 객체 타입에 when 키워드 사용시 속성 값도 조건으로 포함 가능 (가드패턴)

       (의사 코딩 예제로 확인) 
	switch (변수-음식이름) {
	     case 우동:
		역전 우동으로 가자;
		braek;
	     case 김밥:
		지하철 김밥집으로 가자;
		braek;
	     case 순대국:
		순대국 집으로 가자;
		break;
	     defalut:
		선택 음식이 없으니 편의점으로 가자;
	}

  **(java 21 새로운 구문) **
예전(레거시) switch 구문에 가지는 한계
1. 폴스루(Fall-through) : break를 사용하지 않으면, case가 의도치 않게 동작.
2. 표현력 부재 : 값을 반환한 수 없는 구문. 값을 전달하기 위해서 외부에서 변수 선언한 후에 case에서 수정해야 함.
3. 타입 제약 : 사용할 수 있는 타입에 제약. 정수형, 문자형, Enum타입 등이 지원. 어떤 타입의 데이터인지를 검사할 수 없음.

5.3 반복문(Loop문)
 주어진 조건이 true인 경우에 블럭 내에 코드를 반복을 지속

1. for문
  
  syntax
      for (초기화식: 조건식 : 증감식) {
	for 조건이 참일 때 동작할 종속 문장들(실행문들)...;
      }

  초기화식 : 조건식에서 사용할 변수를 초기화
  조건식 : 변수에 대한 연산으로 결과값은 true/false 형식.
  증감식 : 조건식에 사용할 변수에 대한 증감(++/-- 를 많이 사용.)

  예시) 
      for (int i=0; i<=5; i++){
	System.out.print("i의 결과 : " + i);    // 6번 반복
       }

      결과
        i의 결과 : 0
        i의 결과 : 1
        i의 결과 : 2
        i의 결과 : 3
        i의 결과 : 4
        i의 결과 : 5
	
      초기화, 증감식은 ()안에 없어도 됨.
      ex1) 
        int i=0
        for (; i<5; i++) {
	
        }
      ex2)
        int i = 0;
        for (; i<5; ){
	실행문...;
            i++;    // 증감식
        }

2. while
    조건식이 참인 경우에 {}에 있는 내용을 반복.
    
    syntax:
      while (조건식) {
 	반복 실행문;
      }


    ex1)
        int i = 0;     // i에 대한 초기화
        while (i < 10) {
	System.out.println("i의 값 : " + i );
}

3. do - while
 do-while은 while과 비슷하게 동작하지만, 반복 전에 한 번은 실행(do)하는 반복문.
사실 많이 사용하지 않음.
     syntax
         do{
              반복 실행문..;
         }while(조건);

     ex) 
       int sum = 10;
       do{
	sum += 5;        // 1번은 동작 (sum = sum + 5;)
        }while(sum > 15);   //sum이 15보다 크면 반복
        결과 : sum = 15

4. 반복문의 중첩(******)
   반복문의 중첩은 if문의 중첩과 같이. 반복문 안에 반복문이 반복하는 경우.

   syntax 및 예시...
      for (int i =1; i <= 10; i++) {
	for (int j = 1; j <= 10; j++) {
	     반복 실행문;
	}
	int k = 0;
	while(k+i <= 5) {
	       반복 실행문;
	       k += 1;
	}
    }

6. 무한 반복문

         또한, 메모리에 고갈이 날 수 있다.

  for (;;) { }
  while (true) { }
  do { } while (true);
